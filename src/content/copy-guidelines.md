# V4.6 台灣深夜口語文案系統

情緒文字像深夜傳給朋友的 LINE 訊息：自然、安靜、口語、克制，允許一點幽默。操作文字簡短直接，安全文字必須明確。不是諮商、勵志語錄、客服通知，也不預設讀者難過或需要安慰。

## 語言與排版

使用台灣繁體中文：訊息、資料夾、影片、使用者、設定、網路、儲存。避免感嘆號、Emoji、網路流行語與大量語尾助詞。短句可以不加句點；說明仍使用正常標點。

建議按鈕 2–8 字、提示 8–25 字、情緒文字 15–45 字、安全說明 20–60 字；優先清楚，不強制截斷。

主標題／情緒文字使用 Noto Serif TC，一般介面／按鈕使用 Noto Sans TC。信紙保持 Noto Serif TC、17px 基準、行高 2.0、高對比，不模糊、不使用手寫字體。不以動畫延遲或捲動限制強迫讀完文案。

`zh-TW.ts` 只放已接入產品頁的文案。以下文案屬未開放狀態的規範，不能為了展示它們新增假頁面、假信件、假成功狀態。

## 已開放頁面與目前狀態

目前只有 Sprint 01 基礎頁面和本機資料層，沒有編輯、刪除、公開、同步或時光信 UI。首頁和導覽是真正可點的路由入口；寫信仍是預覽。

- 首頁：主標題「不敢傳出去的訊息」；「有些話打了三遍又刪掉，最後連自己都想不起來要說什麼。」；「沒事，放這裡就好。」；「開始寫信」。尚無文字序列動畫，所以直接顯示全文。
- 寫信：「寫下來吧」；「寫給誰都行，寫給自己也不丟人。」；「想說什麼，就從這裡開始寫。」目前以靜態信紙呈現，不是假輸入框；另標示還不能輸入或儲存。
- 私人信箱：標示清單未開放，不使用真正空信箱的文案。
- 星空：標示功能未開放，不把未開發／讀取錯誤寫成「沒有星星」。
- 404：說明網址可能不對，提供回首頁。
- 本機資料：「本機信件只會留在這個瀏覽器。清除網站資料後，就無法復原，也不會自動同步到其他裝置。」

## 信件去向（待接入）

標題「這封信，你想怎麼處理？」

| 操作     | 說明                           |
| -------- | ------------------------------ |
| 留給自己 | 先收著，想看的時候再回來。     |
| 讓它消失 | 不想留著，也可以。             |
| 送往星空 | 讓不認識的人，也有機會讀到它。 |

保留「送往星空」的場景名稱，不暗示指定收件人。公開性質仍須清楚解釋。

## 刪除（待接入）

確認：「這封信刪掉之後，就找不回來了。」「確定要讓它消失嗎？」
按鈕：「再留一下」「確定刪除」。

只有資料交易成功後才能顯示「好了，這封信不在這裡了。」或播放完成動畫。
失敗：「這封信還沒刪掉，先別急著離開。」「可以再試一次。」不得用幽默降低不可逆風險。

未來長按 1.5 秒是安全操作手勢，不屬於 300ms 動畫預算；須有同等可用的鍵盤／輔助技術確認方式，不能用長按取代明確後果說明。這輪沒有刪除 UI，未新增長按行為。

## 公開投稿（待接入）

確認：「送出去之後，不認識的人可能會在夜空中讀到這封信。」「你確定要公開嗎？」
按鈕：「再想一下」「確認送出」。必須保留明確同意、10 秒撤回、後端審核及審核通過才公開。

- 等待公開：「信已經送出去了，還要等一下才會出現在星空。」
- 緩衝期間：「撤回這封信」。
- 審核中：「這封信還在等確認。」
- 後端確認公開後：「好了，這封信在星空裡有位置了。」
- 失敗：「這封信還沒成功送出去。」只有確定文字仍保留時才加「文字還在，可以再試一次。」

請求成功不等於公開成功，飛出動畫也不代表審核完成。

## 私人信箱與同步（待接入）

真正清單已讀取且為空時：「這裡還挺安靜的，像剛搬進來的房子。」

本機交易完成：「收好了，這封信留在這台裝置。」需搭配「這個瀏覽器」的資料範圍說明，避免誤認所有瀏覽器共用。

已登入、同步成功且可跨裝置取回後：「收好了，換台裝置也能找得到。」

同步失敗：「這封信還沒存到雲端。」只有本機確認儲存成功時，才加「目前還留在這台裝置。」本機也失敗時不得顯示。

## 星空閱讀與回應（待接入）

清單載入成功且為空：「夜空中還沒有星星。」可選「目前的亮度，大概只有一隻螢火蟲。」讀取失敗不得使用這兩句。

閱讀後：「讀完了。想留句話給對方嗎？」固定選項「我讀到了」「給你一個擁抱」「願你一切都好」，不新增自由留言。回應成功後：「收到了。」不顯示假數量，不暗示對方已讀。

## 時光信件（待接入）

- 日期：「你想什麼時候再打開這封信？」
- 確認：「封存之後，日期還沒到之前，就不能再打開了。」「想好了嗎？」
- 按鈕：「再想一下」「封存這封信」。
- 成功：「信封收好了。」「未來的你，記得回來看看。」
- 未到期：「還沒到時間。」「這封信先替你收著。」
- 到期：「有封信在等你。」「想看的時候，再打開就好。」
- 拆封：「打開這封信」。

封存後不能改正文、日期、取消或提前拆封；可刪除。到期不自動開啟，雲端由後端時間和權限控制。文案與動畫均不改變這些規則。

## 錯誤文案（待對應真實錯誤 UI）

先說發生什麼事，再說可以怎麼做。不得用幽默掩蓋資料遺失、帳號安全、隱私或公開狀態。

| 情境         | 建議文案及使用條件                                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 本機儲存失敗 | 這封信還沒存好，文字先別關掉。保留可重試的正文。                                                                               |
| 網路中斷     | 目前連不上網路，稍後再試一次。                                                                                                 |
| 驗證失敗     | 驗證沒有成功，請再試一次。                                                                                                     |
| 不存在       | 找不到這封信。                                                                                                                 |
| 無權讀取     | 目前無法開啟這封信。                                                                                                           |
| 未到期       | 還沒到時間，這封信現在不能打開。                                                                                               |
| 審核未通過   | 這封信目前無法公開。                                                                                                           |
| 版本衝突     | 這封信有兩個不同的版本，先選擇要保留哪一個。僅在有真正版本選擇 UI 時使用；目前 repository 要求重新讀取，不能暗示已有選擇功能。 |

這輪不修改資料層錯誤碼、訊息、API 或生命週期。未來在 UI 邊界以錯誤碼對應文案。

## 彩蛋候選，需人工確認

1. 寫了三百字的訊息又全部刪掉，最後只傳了一個 OK。
2. 滑了三遍通訊錄，最後還是把手機關掉了。
3. 其實有很多話想說，但怕說出來會後悔。結果沒說，好像也有點後悔。

這些是原創候選，不是使用者投稿，不加「有人寫過」。目前專案沒有找到 V3.9 的 15 條原文，沒有建立彩蛋元件，也沒有替換或刪除任何既有內容。人工確認前不發布上述候選。
